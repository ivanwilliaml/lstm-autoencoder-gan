# LSTM, Autoencoder & GAN

Individual project: three deep-learning builds in one deliverable.

## Open this first
- [`01_lstm_stock_forecasting.ipynb`](./01_lstm_stock_forecasting.ipynb) — LSTM stock-price
  forecasting (AAPL, AMD), with a baseline, learning-rate check, and activation-function
  ablation compared against each other.
- [`02_autoencoder_dimension_reduction.ipynb`](./02_autoencoder_dimension_reduction.ipynb) —
  autoencoder-based dimensionality reduction.
- [`03_gan_image_generation.ipynb`](./03_gan_image_generation.ipynb) — a GAN trained for
  image generation, with the generator/discriminator training dynamic explained inline.

No dataset is committed here — each notebook documents its source.
